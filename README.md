# Boltzmann Lab

Интерактивная симуляция распределения Больцмана.

## Возможности

- Моделирование движения и столкновений частиц.
- Задание потенциальной энергии U(x).
- Сравнение экспериментального распределения с теорией Больцмана.
- Моделирование различных типов перегородок.
- Режим демона Максвелла.
- Интерфейс на русском и английском языках.

## Требования

- Python 3.11 или новее.
- Зависимости из pyproject.toml.
- Для Windows-сборки с Qt WebEngine требуется Windows 10 версии 1809 или новее.
  Windows 7 не поддерживается.

```powershell
python -m pip install -e ".[build]"
```

Затем из корня проекта запустите:

```powershell

```

Если PowerShell запрещает запуск локальных скриптов, разрешите его только для

```powershell
.\packaging\build_windows.ps1
```

Готовый автономный файл появится в `releases\windows\BoltzmannLab.exe`.

## Управление симуляцией

- В параметрах моделирования «Темп симуляции» задаёт замедление или ускорение
  от 0,05× до 8×. При 1× используется обычный темп. Шаг расчёта физики
  не увеличивается при ускорении; при большом числе молекул ускорение может
  ограничиваться производительностью компьютера.
- В режиме демона Максвелла «Правила пропуска» можно задавать по цвету или
  по скорости. Для медленных и быстрых молекул отдельно выбираются направление
  пропуска и действие при отказе: отражение или вопрос пользователю.
  При выборе правил по скорости по умолчанию быстрые проходят вправо,
  медленные — влево, остальные отражаются.
- «Раскраска молекул» переключает постоянные цвета и динамическую раскраску
  по скорости: красные быстрее порога, синие медленнее или равны порогу.
  Используется полная скорость |v| = √(vx² + vy²) в единицах модели.
  Пороги раскраски и пропуска независимы. Правила по цвету применяются к
  текущему видимому цвету; при возврате к постоянной раскраске сохраняются
  исходные цвета молекул.
- Начальный размер окна выбирается по рабочей области экрана. Разделитель
  между настройками и графиками можно перетаскивать; на небольших экранах
  панели прокручиваются. Масштабирование поля сохраняет пропорции модели.
- Нажатие на заголовок «Потенциальная энергия U(x)» скрывает или открывает
  график, сохраняя потенциал и рисунок. Начало нового рисунка открывает график.

Проверки (в окружении с зависимостями проекта):

```powershell
python -m unittest discover -s tests -v
```

## Показ на проекторе и баланс энергии

Интерфейс использует полужирный шрифт 18 pt, заголовки 22 pt, крупные кнопки
и поля ввода. Подписи осей — 18 pt, деления — 16 pt.
Цвет подписей автоматически выбирается по яркости фона графика;
блок статистики имеет непрозрачный фон. Тема фиксирует цвета
элементов управления, чтобы системная тёмная тема не снижала контраст.
Справочные страницы также отображаются крупным контрастным шрифтом.

После каждого шага интегрирования и раздвигания перекрывающихся молекул
выполняется коррекция модуля скоростей по балансу полной энергии K + U.
Целевая энергия — энергия до шага плюс работа движущейся перегородки.
Это приближённая численная проекция, а не термостат: температура не
подгоняется к заданному числу, обмен между кинетической и потенциальной
энергией сохраняется. Направления и отношения модулей скоростей не меняются.
При изменении потенциала или параметров отсчёт идёт от нового состояния.

Такой контроль устраняет накопление ошибки энергии в этой учебной модели,
но не превращает дискретную обработку столкновений в точную молекулярную
динамику и не гарантирует точное воспроизведение канонического ансамбля.
О различиях сохранения энергии и термостатирования см.
[руководство GROMACS](https://manual.gromacs.org/2022/reference-manual/algorithms/molecular-dynamics.html).

## График свободной энергии

Под статистикой находится сворачиваемый график «Свободная энергия F(t)».
Нажатие на заголовок открывает или скрывает его. При открытом графике
значение F из строки статистики убирается; при закрытом — возвращается.

История записывается и при скрытом графике. По горизонтали — модельное
время: ускорение учитывается, пауза и ожидание решения демона останавливают
отсчёт. Новый потенциал, перераспределение молекул, изменение их числа,
заданной температуры или масштаба потенциала начинают новую историю.
При долгой работе история постепенно прореживается с сохранением начала
и последней точки, чтобы ограничить использование памяти.

График показывает фактическое F, рассчитанное существующей моделью:
никакого принудительного сглаживания или монотонного убывания не вводится.

## Игра «Угадай начало»

Игра открывается через «Симуляция → Угадай начало». Кнопка «Исследование газа»
в том же меню открывает исходную симуляцию. Из каждого режима можно вернуться
к выбору режима, а оттуда — в главное меню. Выберите две, три или
четыре симметричные ямы либо нарисуйте собственный потенциал с 2–6 ямами.
Программа распознаёт ямы и отмечает их номерами. Рисунок нужно применить.

Для одиночной игры оставьте «Случайная яма». Ведущий может выбрать начальную
яму списком или щелчком по применённому потенциалу. Задайте начальную
температуру, высоту барьеров, число молекул и модельное время выдержки.
Начальное состояние и всё движение в течение выдержки скрыты. После её
окончания показывается замороженное конечное состояние; выберите исходную
яму. До ответа настройки заблокированы, начальные графики недоступны.

После ответа раскрываются исходная яма, число оставшихся в ней молекул,
счёт и серия верных ответов. Начальную гистограмму можно наложить пунктиром.
В «Результатах опытов» сохраняются последние 200 ответов с температурой,
выдержкой и числом ям. Ориентир «Наугад» учитывает число вариантов в раундах.

У игры отдельная симуляция; газ не подключён к термостату. Температура
относится к подготовке опыта. Можно исследовать, как меняется угадываемость
начала при разных температурах и выдержках, повторяя много раундов.
График распределения сворачивается нажатием на заголовок и в обычной
симуляции, и в игре.

Для сравнения сохранения памяти удобнее начинать с симметричных ям.
В своём асимметричном потенциале начальные ямы могут иметь разные энергии:
в изолированном газе это само по себе оставляет физическую подсказку о начале.
Маркеры молекул в игре увеличены для проектора; физический радиус столкновений
при этом остаётся прежним.

## Производительность на аудиторных компьютерах

Сохранены ускорения физики и отрисовки. Диапазоны параметров одинаковы
на всех компьютерах: до 2000 частиц и до 25% заполнения площади колбы.
Число частиц, радиус, размеры рассеивателей и положение закрытой перегородки
согласуются непосредственно в панели параметров, без дополнительных сообщений.
Подробности реализации — в [описании оптимизаций и ограничений](docs/performance.md).
