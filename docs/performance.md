# Оптимизации и фиксированные ограничения

Программа использует единые диапазоны на всех компьютерах. Измерения мощности,
калибровка, фоновые тесты, профили производительности и автоматическая пауза
по нагрузке удалены. В интерфейсе нет кнопок проверки мощности, индикаторов
плотности и сообщений о достижении этих пределов: допустимые значения заданы
самими элементами управления.

## Сохранённые оптимизации

- Numba для интерполяции на равномерной сетке, интегрирования, подсчёта и
  коррекции энергии, столкновений частиц и отражений от рассеивателей.
- Повторное использование рабочих массивов пространственной сетки.
- Рисование всех частиц одним скомпилированным вызовом с точными масками Pygame.
- Передача изображения в Qt без транспонирования массива NumPy.
- Кэширование теоретической кривой и неподвижных контуров рассеивателей.
- Пропуск повторной отрисовки неизменного поля на паузе и скрытых графиков.
- Совместный расчёт показаний статистики без повторения одинаковых операций.

Частота изображения — 30 кадров/с; шаг физики — 1/240 модельной секунды.
При темпе ×1 сохраняются 240 шагов за секунду, при ×8 — 1920.
Крупные шаги для компенсации нехватки мощности не используются.
Порядок Verlet, работа перегородки и определение свободной энергии сохранены.
Без Numba остаются варианты на Python/NumPy с теми же диапазонами параметров.

## Единые пределы

Значения находятся в core/limits.py и проверяются также вычислительным ядром.

| Параметр | Диапазон |
|---|---|
| Частицы | 1–2000, дополнительно ограничиваются радиусом |
| Физический радиус | 1–5 пикселей базового поля |
| Начальная температура | 0–10 |
| Масштаб потенциала | 0–12 |
| Темп | ×0,05–×8 |
| Вероятности | 0–1 |
| Положение перегородки | 0,1–0,9 длины поля, с учётом заполнения отсеков |
| Пора | 4–100 пикселей |
| Рассеиватели | 1–8 в колонке, 1–3 колонки; градиентные пресеты используют 5 |
| Размер рассеивателя | 4–40 пикселей, совместно с количеством |
| Скоростные пороги демона | 0–40 |

Площадь дисков составляет не более 25% площади поля:

N × π × r² / (900 × 280) ≤ 0,25.

| Радиус, пиксели | Максимальное N |
|---|---:|
| 1 | 2000 |
| 2 | 2000 |
| 3 | 2000 |
| 4 | 1253 |
| 5 | 802 |

Диапазоны числа частиц и радиуса связаны в обе стороны. Размер и число
рассеивателей подчиняются условию «число × размер ≤ 70», которое раньше
молча уменьшало фактический размер в расчёте.

Ход закрытой перегородки ограничивается заполнением запертых отсеков до 30%.
Это оставляет небольшой запас для сжатия газа, исходно занимающего до 25%
площади колбы. Учитываются закрытые направления полупроницаемой перегородки;
открытые поры и разрешённый проход сохраняются. Доступный ход сразу отражается
в диапазоне выбора положения. Ограничение общей площади не гарантирует
отсутствие локальных перекрытий около узких потенциальных ям и препятствий.

Пора уже диаметра частицы разрешена как осмысленный опыт с непроходимой
перегородкой. В игре сохранены 10–100 частиц, температура 0,01–10, высота
барьера 0,1–12 и выдержка 0,1–120 секунд; дополнительно проверяется площадь ямы.

Потенциал должен быть конечной одномерной кривой в 0–1. Ядро проверяет диапазоны,
NaN, бесконечности, целочисленность дискретных параметров и согласованность
массивов. Аварийная защита от фактической температуры выше 50 сохранена.

## Проверка

~~~powershell
venv\Scripts\python.exe -m unittest discover -s tests
~~~

Тесты проверяют сохранение энергии, совпадение ускоренного расчёта с прежним,
попиксельное совпадение с Pygame, зависимости диапазонов и отсутствие
дополнительных элементов интерфейса для мощности и плотности.
